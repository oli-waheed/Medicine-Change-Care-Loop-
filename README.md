# Software Development Project course template

# Using the Project Assistant

Use `/project-assistant` in chat to use the agent.

The Project Assistant is an AI coach for your software development project.

Its purpose is to help your team:

- review project progress
- identify missing information
- verify decisions and assumptions
- prepare for meetings and reviews
- connect work to project goals
- reflect on learning and teamwork

The assistant supports the team, but the team remains responsible for all decisions.

## What the Assistant Does

The assistant can:

- review specifications, plans, tasks, and code
- identify gaps, risks, and inconsistencies
- ask guiding questions
- help prepare for customer or teacher meetings
- suggest what should be verified next
- help connect requirements, implementation, and testing

The assistant helps you think. It does not do the project for you.

## What the Assistant Does Not Do

The assistant will not:

- make project decisions
- choose technologies for the team
- invent requirements
- approve work on behalf of the teacher
- write assessed reflections
- implement project features
- complete project tasks for the team

## Good Questions to Ask

### Progress Review

> Review our repository. Are we progressing in the right direction?

> What is the most important thing we should verify next?

### Project Planning

> What appears to be missing from our current project plan?

> Are our GitHub Issues aligned with the specification?

### Implementation Review

> Does the implementation appear consistent with the specification?

> What evidence is still missing before we can consider this feature complete?

### Meeting Preparation

> Help us prepare for our next customer meeting.

> What decisions should we ask the customer to make?

### Reflection

> What should the team reflect on after this iteration?

> What have we learned from the recent changes?

## Best Practice

Before asking the assistant:

1. Commit your latest work.
2. Keep specifications and plans updated.
3. Update relevant GitHub Issues.
4. Document important decisions.

The assistant can only review evidence that exists in the repository.

## Important

Do not ask:

> "Please solve this project for us."

Ask instead:

> "Help us evaluate our current solution."

The goal is not to get answers quickly.

The goal is to learn how professional software projects are planned, implemented, reviewed, and improved.

**The Project Assistant is most useful when you ask it to review, challenge, and verify your work rather than generate solutions.**
